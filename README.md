# borck.education

Single-page hub linking six educational properties:

- [tools.borck.education](https://tools.borck.education) — privacy-first apps, CLIs, and libraries for teaching and learning
- [books.borck.education](https://books.borck.education) — books on intentional AI collaboration
- [teach.borck.education](https://teach.borck.education) — workshops, courses, and executive education
- [simulations.borck.education](https://simulations.borck.education) — simulated organisations for hands-on learning
- [security.borck.education](https://security.borck.education) — the Assume-Breach series of hands-on security labs
- [programming.borck.education](https://programming.borck.education) — Speak Software labs, HandsOnAI toolkit, programming toys, and published packages

Plain HTML, no build step. Deploys via GitHub Pages.

MIT licensed.
